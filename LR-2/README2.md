# Сумма двух (Two Sum)

## Задание
Функция `add(nums, target)` возвращает индексы двух чисел из массива `nums`, дающих в сумме `target`.

## Реализация
Файл `sum.py`. Использован словарь для поиска за один проход — O(n).

## Тесты
Файл `test_sum.py`, библиотека `unittest`.
